# 制作方法与关键修改记录

## 1. 工具与材料

- AI 图像生成：根据角色参考和构图要求生成、修改画面。
- Windows 画图：调整最终图片的像素尺寸并另存为 PNG。
- GitHub 网页端：整理作品、过程图与说明文档。

角色参考来自提供的 Meowdoku 图标、宣传图与游戏截图。
竞品图片用于研究构图关系，角色形象以 Meowdoku 为依据。

## 2. 角色一致性控制

生成时重点约束：
- 黑色头顶与耳朵。
- 额头中央白纹和圆润白色嘴套。
- 粉色鼻子、大棕色眼睛。
- 白色胸腹、爪子和尾尖。
- 统一的柔软 3D 质感和温暖配色。

后续画面沿用角色参考，并使用已生成的图像作为修改依据。
通过人工对照选择保留版本。

## 3. 关键修改指令

以下记录来自制作对话中的实际要求。
这是关键指令摘录，不是完整模型提示词或生成参数。

### 从侧边探头改为俯看落子

实际提出的要求：

> 这个主视觉图考虑猫咪俯视整个棋盘，一只爪子可以从上向下放在棋盘一格上。

修改目的：
让主角参与解题，通过目光和前爪动作建立角色与棋盘的联系。

修改后关注：
前爪是否自然、是否遮挡过多格子，以及耳朵是否贴近画面边缘。

### 加强画面构图张力

上传构图参考后提出：

> 参考这种画面构图张力呢？

参考中提取的构图特点：
- 低机位。
- 前景棋盘近大远小。
- 前爪伸向观众。
- 角色与文字分区。

将这些关系应用到 Meowdoku 主角，保留产品角色的棕眼、黑白花纹和 3D 质感。

### 最终文案选择

最终保留：
- FIND THE LAST CAT.
- Where does it belong?
- PLAY NOW

使用“寻找最后一只猫”交代具体挑战，并通过按钮引导行动。
历史版本中的其他标题保留在过程图中。

## 4. 主角变体

归档六种角色状态：
- 思考
- 发现
- 探头
- 休息
- 喜爱
- 扑跃

通过动作、表情、道具和视角变化拓展角色表现。
统一参考同一主角，检查花纹、五官和画风的一致性。

当前归档包含六张选定变体；未保存的中间版本不补造记录。

## 5. 人工决策与操作

提交者参与：
- 提供产品角色与玩法参考。
- 提出俯看棋盘、伸爪落子等构图修改要求。
- 提供更具张力的构图参考。
- 选择归档版本并确定最终文案。
- 整理三种画幅与六张角色变体。
- 调整导出尺寸并进行人工对照检查。
- 整理 GitHub 文件和制作说明。

AI 工具承担图像生成与修改，制作说明如实区分人工决策与工具生成。

## 6. 文件说明

- process：保留的制作过程与选图版本。
- final/main：三种尺寸的最终主图。
- final/variants：六张角色变体。
- docs/iterations.md：版本展示与导出记录。

本次图像为位图产物，不包含分层 PSD 或 3D 模型。
